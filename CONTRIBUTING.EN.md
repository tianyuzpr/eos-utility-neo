## Ways to Contribute

Contributing to this project is not limited to code. You can also contribute in the following ways:

- Submit code (via Pull Request or become a developer with direct `git push` access)
- Report issues (via Issue)
- Suggest new features (via Issue)
- Write documentation for the project (via Pull Request or become a documentation writer with direct `git push` access)
- Spread the word about this project — your promotion is our greatest affirmation

## Pull Request Guidelines

Your Pull Request must comply with the following guidelines:

### For Code:

- Please ensure your code conforms to the `PEP-8` style guide as much as possible
- Please add necessary comments in your code to explain its functionality and implementation
- Code entirely generated by AI large language models must be fully reviewed by a human and marked with an "AI-generated" header
  - Code suspected of being AI-generated (i.e., having an "AI flavor") will not be accepted unless marked with "AI-generated" or accompanied by proof of manual authorship
- Please ensure your code is clear, readable, and maintainable
- Please write test cases whenever possible (saved in the `tests` directory)
- Please ensure your HTML responses conform to standard HTML format, e.g., correct use of status codes

### For Documentation:

- Please ensure your documentation is clear, accurate, and compliant with Markdown specifications
- Please ensure your documentation is free from grammatical errors, ambiguities, or other issues that affect comprehension
- Documentation entirely generated by AI large language models must be fully reviewed by a human and marked with an "AI-generated" header
  - Documentation suspected of being AI-generated (i.e., having an "AI flavor") will not be accepted unless marked with "AI-generated" or accompanied by proof of manual authorship
- Please provide bilingual documentation in both Chinese and English. If you are not a native speaker of Chinese or English, you may use AI or machine translation, but you must add the following disclaimer at the top of the document:

## Issue Guidelines

Your Issue must comply with the following guidelines:

- Please strictly follow the Issue template when filing an Issue
- Please include necessary information in your Issue, such as a description of the problem, steps to reproduce, expected results, etc.
- Issues that cannot be reproduced or are difficult to reproduce will be deferred
- Please ensure you have carefully read the documentation and confirmed that the same issue has not been submitted elsewhere before filing an Issue
- For new features you would like to propose, please first confirm whether the same functionality already exists in this project (including development branches)
