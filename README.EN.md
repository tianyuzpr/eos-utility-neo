## Project Description

This project is built on Canon EDSDK, aiming to deliver a modern remote control experience for classic EOS cameras.

The original EOS Utility 2.x features an outdated interface and poor compatibility with modern operating systems, while the 3.x release no longer supports older models such as the EOS 5D Mark II. EOS Utility Neo addresses this gap by offering a brand-new WebView-based UI, along with improved support for current platforms — giving timeless cameras a new lease on life.
