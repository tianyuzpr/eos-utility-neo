## 项目描述

本项目基于佳能 EDSDK 开发，旨在为老款 EOS 相机提供现代化的遥控拍摄体验。

原版 EOS Utility 2.x 界面陈旧，对新系统兼容性较差；而 3.x 版本已不再支持老款机型（如 EOS 5D Mark II）。本项目正是为此而生——基于 WebView 构建全新 UI，同时适配现代操作系统，让经典相机焕发新生。
